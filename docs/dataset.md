# Dataset

Status: stub — populated in Phase 5 (Module C training data).

Any third-party dataset used by this project (the leading candidate is HC3,
the human-vs-ChatGPT comparison corpus) will be documented here with:

- Exact source and version/commit.
- License, and how that license permits this project's use.
- A setup script that downloads it at setup time (`apps/api/scripts/` —
  added in Phase 5), not a copy bundled into this repo.
- Any preprocessing applied before training.

No dataset is bundled in this repository. No copyrighted text is scraped or
embedded as demo/training data anywhere in this project — see the root
README's disclaimers.
